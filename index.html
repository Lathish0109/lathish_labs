Bug tracking · Stable

ErrorZero

A bug-tracking and issue-management tool for QA and engineering teams, with role-based access, CI and Playwright integration, and security built in from day one.

  • Dashboard with active bugs by status and priority, plus a resolution trend
  • Bug triage filterable by project, status, priority, and date
  • Structured bug reports with severity, labels, and steps to reproduce
  • Analytics with resolution time, opened vs. closed trends, and CSV export
  • Automation API keys so Playwright and CI jobs file bugs directly
  • Admin, Manager, Tester, and Developer roles with project scopes

Security: audit logs, sanitized inputs, local encryption keys, and no third-party telemetry by default.

AI test pipeline

QAPipeX

Takes a plain-language requirement all the way to an executed, evidence-backed test result. You approve every test the AI writes before anything runs.

  1. Describe or import. Write a requirement, or import existing test cases from Excel or CSV.
  2. Review. AI drafts Playwright steps from the real elements on your page. You approve them.
  3. Run. A real browser runs approved tests. Failures are retried once, so flaky tests are flagged, not filed.
  4. Diagnose. Each failure gets a screenshot, a trace, the console log, and an AI analysis that separates evidence from guesses.
  5. Report. New failures become bug reports in ICore Bug Tracker. Repeat failures link to the existing bug.
